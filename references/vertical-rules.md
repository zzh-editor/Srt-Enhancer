# 竖屏字幕断句规则（9:16 Vertical Subtitle Rules）

针对 9:16 竖屏视频的字幕断句规范。竖屏字幕在手机上单屏可见区域小，每行能容纳的字数远少于横屏，因此需要对横屏字幕做**基于语义的进一步断句**，而不是简单按字数硬切。

## 数据来源

规则提炼自两份人工精校字幕的对比：

- 横版（16:9）：146 条，每行 2-28 字（平均 14.8），时长平均 2.61s
- 竖版（9:16）：244 条，每行 3-16 字（平均 8.1，集中在 4-12 字），时长平均 1.39s

竖版不是横版的简单压缩，而是同一段内容的**语义重断句 + 时间轴重排**：一句话被拆成多个短行，每行是一个完整的语义单元。

## 核心规则

### 1. 行长：每行 4-12 字，目标约 8 字

- 上限 12 字（超过就应断句）
- 平均约 8 字最舒服
- 短行（4 字）出现在语义完整、需要单独强调的小句上

示例（横 → 竖）：

| 横版（1 行） | 竖版（拆成多行） |
|-------------|-----------------|
| 那今天呢我会用一个视频给大家讲清楚 | 今天我将用一个视频 / 来跟大家讲 |
| 假如你想大学一毕业的时候就进入到心仪的大厂的项目组 | 如果说你想一毕业的时候 / 就进入到 / 你心仪的大厂的项目组 |

### 2. 断句位置：在语义边界切，不硬切

每行必须是一个完整的语义单元，优先在以下位置断：

| 断句位置 | 例子 |
|---------|------|
| 动宾结构后 | 今天我将用一个视频 → 来跟大家讲 |
| 主谓结构后 | 大概率你会拿到 → 你满意的这个结果 |
| 连接词/假设词后 | 如果说你想一毕业的时候 / 就进入到 |
| 短语/意群边界 | 时间上的一个规划 |
| 修饰语与被修饰语之间 | 你心仪的大厂的项目组 |

### 3. 时间轴：按字数比例重排

竖版重新分配每条的时间范围，每块约 1.0-1.9s。确定性的做法是按各 chunk 的字数比例分摊原段时间：

```
chunk_dur = 原段总时长 × (chunk 字数 / 原段总字数)
```

保留整个原段时间范围，只把内部切成多块，字幕与语音仍对齐。

### 4. 内容保真

竖屏管线**只改断句和时间轴，不改文本**。断句后拼接回原文必须逐字一致，不一致则放弃该条断句、保留原行。

## 与其他处理的关系

- 竖屏转换应在**润色（srt-enhancer 增强管线）之后**执行：先做去口癖、术语、标点等文本修正，再断句
- 竖屏转换**不包含**翻译、去口癖等增强步骤，那些已由主管线完成
- 输出文件命名为 `{源文件名}_竖屏.srt`
