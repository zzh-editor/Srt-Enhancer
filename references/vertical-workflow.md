# 竖屏输出流程

竖屏输出是普通润色后的独立后处理，只调整断句和时间轴，不改文本、不覆盖普通 SRT。

## 执行

输入应为已审核的增强字幕。逐条生成语义切分计划：每个 chunk 不超过 12 字，优先保持 4–12 字，并在动宾、主谓、连接词或短语边界切分；已经足够短的条目不必放入计划。

```json
{"1": ["今天我将用一个视频", "来跟大家讲"], "2": ["如果说你想一毕业的时候", "就进入到"]}
```

运行脚本时，`--words-json` 仅在词级时间文件与当前 SRT 对应时传入：

```bash
python3 scripts/vertical.py "<enhanced_srt>" \
  --splits "<scratch_dir>/vertical-splits.json" \
  --words-json "<matching_words_json>" \
  -o "<output_dir>/<source>_竖屏.srt"
```

词级文本能对齐时按词边界分配时间；不能对齐时按 chunk 字数比例在原条目时长内分配。计划不合法或 chunk 拼接不能还原源文本时，脚本保留原条目或报错；不要输出未经校验的竖屏文件。没有语义计划时，只有用户接受自动按标点与长度切分，才运行 `--max-chars 12`。

## 校验

- 逐条拼接竖屏 chunk，去掉格式空白后与增强源字幕文本一致；任何文字增删或顺序变化都不通过，不一致的条目保留原行。
- 输出 SRT 可解析，编号连续，条目时间递增且不超出源时间范围。
- 展示 3–5 条样例和输出路径。输出为单独的 `{源文件名}_竖屏.srt`；不删除输入或普通增强版。

`video-transcribe` 在输出阶段可把 `tmp/final.srt` 作为 `<enhanced_srt>`，并传入与该字幕对应的 words JSON。

## 低 Token 增量修订（可选）

字幕过长、只需复核少数条目时，可先用 `--export-uncertain` 导出超长或低置信度字幕的无时间戳清单；确认文本修订后用 `--apply-patch` 回填。该模式会改动文本，不属于纯竖屏重断句；必须按普通增强流程展示 diff 并取得用户确认，不能直接当作竖屏输出写出。
