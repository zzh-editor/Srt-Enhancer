# SRT 字幕优化

适合手里已有 `.srt`，想清理口癖、修正识别错误、整理中英文混排或统一术语的剪辑人员。它不负责听写音视频，也不翻译字幕。

## 普通字幕优化

在 Agent 客户端里附上字幕文件，说明想怎么处理：

```text
优化这个字幕，主要是 Maya 课程，保留说话语气。
```

开始前，客户端会确认你还没说明的偏好，例如中英文空格、领域策略，以及是否给英文术语加中文括注。已在请求里写明的要求不会重复问。术语括注默认关闭。

处理完会先展示修改对照。你可以全部接受、逐条确认或全部拒绝；确认前不会生成修改后的字幕。普通输出文件名为 `{原文件名}_Enhancer.srt`，原文件不会覆盖。编号、条目数、时间轴和原意都会保留；不确定的改动会标出来。

## 9:16 竖屏字幕

对已经准备好的字幕直接说：

```text
把这份字幕导出成 9:16 竖屏版。
```

竖屏流程只重新断句和分配时间，不改字幕文字；普通字幕和竖屏字幕是两个独立文件。输出为 `{原文件名}_竖屏.srt`。需要先优化再做竖屏版时，把两件事一起说明。

## 常用说法

- “清理这个字幕，领域是 Python。”
- “关闭中英文之间的空格。”
- “给英文专业术语加中文解释。”
- “只预览修改，不要写文件。”
- “检查这份字幕的术语大小写。”

技能会在审核时检查作品名、术语和短英文残片。确认过的术语修正可用于后续字幕。若客户端还没安装此技能，可从 [Srt-Enhancer 仓库](https://github.com/zzh-editor/Srt-Enhancer) 添加；具体安装位置由客户端决定。
