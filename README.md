# SRT Enhancer

整理已有 SRT 字幕：去掉口癖，校正常见识别错误，统一中英文空格、术语大小写和标点。它不负责转录音视频或翻译字幕。

处理结果会先显示修改预览。确认后才会生成新文件，原字幕保持不变。

## 快速开始

```bash
npx skills@latest install https://github.com/zzh-editor/Srt-Enhancer
```

在支持 Agent Skills 的 CLI 中，输入“优化字幕”并附上 `.srt` 文件路径即可使用。

## 使用方式

基础优化：

```text
优化这个字幕 meeting.srt
清理字幕 lecture.srt
```

需要时也可以指定领域、调整中西文空格，或为英文术语添加中文解释：

```text
优化字幕 code.srt，领域是 Python
优化字幕 tutorial.srt，关闭中西文空格
优化字幕 tutorial.srt，给英文术语加中文括注
```

预览但不写文件：

```text
优化字幕 draft.srt --dry-run
```

普通输出为 `{文件名}_Enhancer.srt`，保存在原文件旁边。优化会保留字幕编号、条目数和时间轴。

## 竖屏字幕输出（9:16 Vertical）

先完成普通优化，再请求竖屏版本：

```text
把 meeting_Enhancer.srt 导出为竖屏字幕
```

竖屏版会把长字幕拆成更短的语义行，原文不改；每条拆分后拼接必须与原文一致。输出文件名为 `{文件名}_竖屏.srt`。

## Pipeline 步骤

| 步骤 | 处理内容 |
|------|----------|
| 清理 | 去口癖、重复词，修正常见“的/得/地”和比例写法 |
| 术语 | 按领域词表校正术语和大小写 |
| 混排 | 处理中英文空格，同时保护代码、路径和专名 |
| 标点 | 清理多余标点并规范快捷键写法 |
| 复核 | 检查作品名、未匹配术语和英文残片 |
| 修改预览 | 按置信度列出改动；你确认后才写出文件 |

低置信度的同音字修正会标出来，不确定的内容保留原文，交由你确认。

## 专名保护系统

术语表和代码保护规则会避免拆开产品名、软件名、代码、公式和文件路径。确认过的专名大小写也会用于后续字幕。

## 增量术语学习

你确认的术语修正会保存到本地 `correction-table.md`，后续处理时可直接复用。
